# 客户端软件与内核

v2rayN 是有按钮和列表的管理界面；Xray、sing-box 是负责网络连接的内核。可以类比播放器界面与解码器：界面能打开文件，不代表里面的解码器支持所有格式。

本机 v2rayN 显示 V7.24.4 X64，附带 Xray 26.2.6 和 sing-box 1.12.22。本次服务器使用 Xray 26.7.28，REALITY 默认最低客户端版本为 26.3.27，所以只看“v2rayN 是新版”不足以判断兼容。

为了隔离验证，本次从官方发布下载 Xray 26.7.28 到仓库外，使用本机 sing-box 文件的可执行副本做其他测试。原程序、已有节点和当前系统代理保持原状。最终可用组合见 [[06-连接验证与结果]]。

不同内核的 JSON 字段不一样，例如 Xray 的 `streamSettings` 与 sing-box 的 `transport`。不要把一家的配置直接塞给另一家。

来源：[v2rayN](https://github.com/2dust/v2rayN)、[Xray](https://github.com/XTLS/Xray-core)、[sing-box](https://sing-box.sagernet.org/)。
