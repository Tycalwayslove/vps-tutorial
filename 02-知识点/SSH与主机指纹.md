# SSH 与主机指纹

SSH 是通过加密连接远程操作电脑的方法。先确认服务器身份，再验证登录账号，随后才能执行远程命令。

服务器也有自己的身份证明：主机公钥。指纹是这份公钥的简短摘要，常以 `SHA256:` 开头。你的电脑通常把见过的主机公钥记在 `~/.ssh/known_hosts`。

第一次连接时，需要核实新指纹。以后如果同一地址换了公钥，SSH 会提醒你。原因可能是重装或迁移，也可能是连接到了错误的机器；报错本身不能告诉你具体原因。

本次 tyccc 就出现了旧记录不一致。我们通过已经登录的 CloudCone 控制台进入其远程屏幕，在服务器本机运行：

```bash
ssh-keygen -lf /etc/ssh/ssh_host_rsa_key.pub
```

然后与网络连接取得的 RSA 公钥指纹逐字比较。确认一致后，才把已核实的公钥保存到本项目独立的记录文件。没有直接删除电脑里全部旧记录。

这和登录密码是两件事：主机指纹帮助你确认“对方是谁”，密码帮助对方确认“你是谁”。私钥与密码应保密，公开主机指纹一般不等于泄露私钥。
