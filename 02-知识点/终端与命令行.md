# 终端与命令行

终端是输入文字命令、查看输出的窗口。iTerm2、系统终端、FinalShell 都可以提供这样的入口。浏览器里的 noVNC 则展示服务器的远程屏幕，也能在屏幕上的终端输入命令。

一条命令常由“程序名、选项、对象”组成。例如：

```bash
ls -l /etc/ssh
```

`ls` 是列出文件的程序，`-l` 要求详细显示，`/etc/ssh` 是要查看的目录。按回车执行；结果出现后，通常会再次显示提示符，表示可以输入下一条命令。

输入密码时屏幕没有星号，也没有圆点，是 Linux 终端常见行为。正常输入后按回车即可，不要因为看不见字符而重复输入。

复制命令时保留英文符号。`_`、`-`、`/` 含义不同；中文引号也不能随意替换英文引号。本次 noVNC 自动输入会丢失部分符号，导致“找不到文件”，问题出在输入后的文字，不在文件本身。

先分清本地和远程：在 Mac 上运行 `pwd` 查看的是 Mac；SSH 登录后运行相同命令，查看的是 VPS。关闭 SSH 连接通常不会关闭已经由系统服务管理的程序。
