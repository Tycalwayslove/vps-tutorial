# 住宅 IP 与机房 IP

“IP 在哪里”“属于哪个网络”“谁在使用它”“网站是否接受请求”是不同的问题。把它们都称作“纯净度”，会让人误以为一个分数就能决定所有事情。

| 名称 | 通常在描述什么 | 单凭名称不能证明什么 |
| --- | --- | --- |
| 机房 IP | 与托管、云或数据中心网络相关的地址 | 不能推断所有网站都拒绝它 |
| 住宅 IP | 与面向住户的接入网络相关的地址 | 不能保证独享、没有历史滥用或不会被标记为代理 |
| ISP 代理、静态住宅 | 商家的产品分类，具体实现可能不同 | 不能只凭“静态”证明实际位于家庭宽带 |
| ASN | 一个自治网络的编号，帮助理解网络归属 | 不证明某台机器在真实住户家里 |

IP 数据库本身可以单独标记住宅代理。例如 MaxMind 的匿名 IP 数据库有 `is_residential_proxy` 字段。因此，“属于住宅 ISP”不能推出“无法被识别为代理”。这是由分类字段得出的限制，不是对某个商家的检测结论。[MaxMind 字段说明](https://dev.maxmind.com/geoip/docs/databases/anonymous-ip/)

## 你买到的究竟是什么

**代理端口服务**通常给你服务器地址、端口及认证信息。它像一个可以交付请求的窗口，一般不给你登录系统、安装 3x-ui 的权限。端口中的入口 IP 也不一定就是网站最终看到的出口 IP。

**VPS 服务**给你一台可管理的虚拟机器，通常可用 SSH 登录。若商品同时宣传住宅出口，还要核实出口、限制和资源安排，不能仅凭“住宅 VPS”四个字判定优劣。

## 核实一项服务时记录什么

记录供应商对资源与授权的说明、是否独享、出口能否固定、带宽和并发限制、TCP/UDP 支持情况，以及实际出口查询结果。IP 归属和代理数据库可以辅助判断，要写清查询来源与日期；单个检测网站的标签不是永久保证。

网站的账号策略还可能考虑使用行为、地区和其他信号。因此本教程不承诺“更换住宅 IP 就不会封号”，也不把无法访问某网站直接归因于机房 IP。

当前没有把 meu 或 tyccc 验证为住宅 VPS，没有购买或接入住宅代理。二者的已有部署仍按实测记录描述。链式结构见 [[链式代理与中转落地]]。
