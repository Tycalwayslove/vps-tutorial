# 文件路径与权限

路径告诉电脑去哪里找文件。`/root/cert/tyccc-ip/privkey.pem` 是**服务器**磁盘上的绝对路径；它不表示你电脑桌面上的同名文件。`../Assets/图片.png` 是从当前笔记目录往上一层再进入 Assets 的相对路径。

Linux 的 root 家目录是 `/root`，命令里的 `~` 通常表示当前用户的家目录。开头的 `/` 表示文件系统根目录，不是网址。

`chmod 600 文件` 表示所有者可读写，其他用户无权限；`chmod 700 程序` 表示所有者还可执行。执行权限是启动程序的条件之一。本次本机附带内核文件缺少执行权限，先复制到私人目录再设置权限用于测试。

权限不能防止你主动把文件上传到 Git。备份和节点 JSON 仍要放在仓库外。参见 [[Git与版本控制]]。

来源：[GNU chmod](https://www.gnu.org/software/coreutils/manual/html_node/chmod-invocation.html)。
