# 从零开始搭建自己的 VPS 代理服务

这是一份跟随真实操作编写的 Obsidian 教学知识库。实验从已有的 meu 服务器出发，在 tyccc 上搭建并验证服务。根目录就是当前文件夹；在 Obsidian 中选择“打开本地仓库”，选中它即可。

> 部署与本次验收已完成：tyccc 的六种入口均通过真实 HTTPS 出口验证，Shadowsocks 与 Hysteria2 另通过 UDP 测试。面板 v3.7.0，服务端 Xray v26.7.28。精确客户端版本和验证边界见下方第 6 课。

> 当前面板访问方式：2026-09-07 按用户要求改为公网 HTTPS，直接用完整公网地址登录，无需先开 SSH 隧道。见 [第 8 课](01-实操/08-开放公网HTTPS面板.md)。真实地址与凭据保存在仓库外的私人连接信息中。
