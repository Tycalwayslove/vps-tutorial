# 从零开始搭建自己的 VPS 代理服务

这是一份跟随真实操作编写的 Obsidian 教学知识库。实验从已有的 meu 服务器出发，在 tyccc 上搭建并验证服务。根目录就是当前文件夹；在 Obsidian 中选择“打开本地仓库”，选中它即可。

> 当前状态：实操进行中。尚未完成的部署与验证不会写成已经成功。

## 怎么阅读

先读 [[00-导航/学习路线]]，再按顺序操作。不懂的词可以点击链接，读完后返回。每个操作章节都应说明目标、准备、操作、原理、成功标准和排错。

## 内容组织

- `00-导航/`：学习路线、实验边界、进度。
- `01-实操/`：按顺序的操作步骤。
- `02-知识点/`：一个概念一篇短文。
- `03-协议/`：协议的区别与配置说明。
- `04-运维与排错/`：验证、备份、恢复和故障处理。
- `05-探索记录/`：实际观察、决策和验证证据。
- `06-参考资料/`：原始出处及查阅日期。
- `Assets/`：经过脱敏的真实截图。

仓库只保存教学材料。服务器密码、面板凭据、私钥、订阅地址和未脱敏截图存放在仓库外。文档中的示例地址不能直接用于连接。
