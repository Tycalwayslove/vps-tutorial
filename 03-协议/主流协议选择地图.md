# 主流协议选择地图

先把一个方案配置正确并验证，再增加第二个。协议多不等于效果好；每一条都增加需要维护的参数和端口。

## 本次实验范围

| 方案 | 学习重点 | 证书条件 | 本次安排 |
| --- | --- | --- | --- |
| VLESS＋TCP/RAW＋REALITY | 目标、SNI、公私钥、Vision | 不需要自己的传统 TLS 证书 | 主线实验 |
| Shadowsocks 2022 | 算法、密钥长度、TCP/UDP | 协议自身加密 | 主线实验 |
| VLESS＋WebSocket＋TLS | 路径、TLS、ALPN | 自有 IP 证书 | 主线实验 |
| VMess＋WebSocket＋TLS | UUID、时间同步、传输组合 | 自有 IP 证书 | 对比实验 |
| Trojan＋TCP/RAW＋TLS | 密码认证与 TLS | 自有 IP 证书 | 对比实验 |
| Hysteria2 | UDP、QUIC、TLS、带宽参数 | 自有 IP 证书 | 对比实验 |

meu 的 VMess 入站显示 WS 而没有 TLS。本次将给 tyccc 的 VMess 实验加 TLS，并解释这项差异。VMess 自身的加密与外层 TLS 是不同层次，不能把“没有外层 TLS”简单写成“所有内容完全明文”。

## 为什么 tyccc 看起来和 MEU 不一样

tyccc 是从空白服务器搭建的六协议教学环境，不是 MEU 的一比一克隆。因此差异是有意设计的，不是面板升级后自动改写了协议。

3x-ui 列表中的彩色小标签也要分层阅读：紫色是**协议**（如 `vmess`），绿色是**传输**（如 `WS`、`TCP/UDP`），蓝色是**安全层**（如 `TLS`、`Reality`）。`VMess + WS + TLS` 是三个字段的组合，不是一种叫“VMess WS TLS”的全新协议。

| 组合 | MEU | tyccc | 这样安排的原因 |
| --- | --- | --- | --- |
| VLESS + TCP + REALITY | 有 | 有 | 两台都保留主线方案，便于对照 REALITY 与 Vision。 |
| Shadowsocks + TCP/UDP | 有 | 有 | 两台都有一个兼容性较强且支持 UDP 的入口。 |
| VLESS + WebSocket + TLS | 有 | 有 | 两台都保留标准 TLS/WebSocket 组合；tyccc 使用自己的 IP 证书。 |
| VMess + WebSocket | 有，无额外 TLS | 有，额外加 TLS | tyccc 专门加入 TLS 对照，演示 VMess 协议保护与 TLS 服务端身份验证是两层不同东西。 |
| Trojan + TCP + TLS | 没有 | 有 | tyccc 额外加入的第六条对比实验，用来学习“密码认证 + TLS”的组合。 |
| Hysteria2 + UDP + TLS | 有 | 有 | 两台都保留 QUIC/UDP 方案。列表行有时只显示 `hysteria` 与 `UDP` 标签；实际安全页仍配置 TLS 和 `h3`，不能因为蓝色 TLS 标签未显示就关闭证书校验。 |

所以 tyccc 的六条是“MEU 的五类经验 + VMess TLS 与 Trojan 的额外对照”。如果你希望两台完全一致，可以另建一套镜像入站，但这会增加端口、凭据和证书维护量；当前不建议删除 tyccc 的 Trojan 或 VMess TLS，它们已完成真实连接验证并承担教学对照作用。具体表单填写见 [[04-浏览器配置六种入口]]；MEU 现有五条的逐字段解释见 [[10-MEU五个入站逐表单配置]]。

## 放在拓展阅读中的方案

WireGuard 是三层 VPN，涉及地址分配和路由；它与应用代理的使用方式不同。SOCKS/HTTP 常作为本机客户端入口，不应直接配置成任何人都可访问的公网开放代理。

XHTTP、gRPC 是传输方式，不是与 VLESS 完全同级的“替代协议”。它们可作为理解分层后的下一课，本次不把所有组合都开启。视频笔记提到的 XHTTP 另见 [[XHTTP与传输选择]]，CDN 条件见 [[CDN与DNS代理状态]]；改变下一跳出口则是 [[链式代理与中转落地]] 的范畴。

表中六种组合已完成创建和实际通信验证，精确客户端版本与边界见 [[06-连接验证与结果]]。VLESS REALITY 和 VMess 使用 Xray 26.7.28 验证通过，其他四种使用 sing-box 1.12.22。Xray v26.7.28 对 Shadowsocks、VMess、WebSocket、Trojan 的部分用法输出弃用提示；它们仍作为兼容性教学案例，未来支持情况不能保证。

本次未部署 WireGuard、TUIC、OpenVPN，也未开启所有传输排列组合。范围是覆盖 meu 已有的主要方案并加入 Trojan 对照；后续课程可分别添加这些独立主题。
