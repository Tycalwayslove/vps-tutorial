# 03 · 签发 IP 证书与自动续期

上一课：[[02-安装面板与SSH隧道]]。TLS 节点需要证明服务器身份，本次没有要求用户另购域名，使用 Let's Encrypt 为 tyccc 的 IPv4 签发证书。先读 [[TLS证书与HTTPS]]、[[ACME与证书续期]]。

**时间背景很重要：** Let's Encrypt 已于 2026 年向公众提供 IP 证书，使用约 160 小时的短有效期。旧文章中的“IP 不能申请免费证书”不适用于本次条件。[官方公告](https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability)

## 为什么先检查 TCP 80

证书机构会从公网连接你的 IP 的 TCP 80，通过 HTTP-01 挑战验证控制权。命令里的 `--standalone` 让 acme.sh 临时启动验证服务，不需要永久运行 Nginx。

```bash
ss -lntp
```

确认 80 没有被别的程序占用，并在服务商防火墙和系统防火墙允许到达它。本次服务器未启用额外入站阻断，80 空闲。完成验证后临时监听自动退出；以后续期仍需要能使用 80。不要因为平时看不到监听就认为配置错误。

## 安装本次使用的 ACME 客户端

以下都在 **服务器终端**执行：

```bash
umask 077
mkdir -p /root/tutorial-acme-source /root/cert/tyccc-ip
curl -fL https://github.com/acmesh-official/acme.sh/archive/refs/tags/3.1.4.tar.gz -o /root/tutorial-acme-source/acme-3.1.4.tar.gz
tar -xzf /root/tutorial-acme-source/acme-3.1.4.tar.gz -C /root/tutorial-acme-source
cd /root/tutorial-acme-source/acme.sh-3.1.4
./acme.sh --install --home /root/.acme.sh
/root/.acme.sh/acme.sh --set-default-ca --server letsencrypt
```

`umask 077` 让新建文件默认只对当前用户开放；`mkdir -p` 创建目录；`tar -xzf` 解开压缩包；`cd` 切换目录。acme.sh 是申请和续期工具，Let's Encrypt 是签发证书的机构，两者不是同一个东西。

## 签发和安装

将下面两处 `VPS_IP` 换成真实 IPv4：

```bash
/root/.acme.sh/acme.sh --issue --server letsencrypt -d VPS_IP --standalone --certificate-profile shortlived --keylength ec-256 --days 3
/root/.acme.sh/acme.sh --install-cert -d VPS_IP --ecc --key-file /root/cert/tyccc-ip/privkey.pem --fullchain-file /root/cert/tyccc-ip/fullchain.pem --reloadcmd 'systemctl restart x-ui'
chmod 600 /root/cert/tyccc-ip/privkey.pem
```

| 参数或文件 | 含义 |
| --- | --- |
| `-d VPS_IP` | 要认证的身份就是该 IP |
| `--certificate-profile shortlived` | 请求短期证书配置档 |
| `--keylength ec-256` | 创建椭圆曲线私钥 |
| `--days 3` | 客户端续期时间安排；不会把机构签发的有效期改成三天 |
| `fullchain.pem` | 服务器证书和中间证书链，客户端用它验证身份 |
| `privkey.pem` | 证明你持有该身份的私钥，不能分享 |
| `--reloadcmd` | 证书部署后重启 x-ui，让服务使用新证书 |

不要直接让面板引用 acme.sh 的内部工作文件。`--install-cert` 设置稳定的部署路径，并登记后续更新动作。

## 核对身份、日期和定时任务

```bash
openssl x509 -in /root/cert/tyccc-ip/fullchain.pem -noout -dates -issuer -ext subjectAltName
crontab -l
```

本次证书记录：签发者 Let's Encrypt YE1；开始时间 **2026-09-07 08:02:34 UTC**；到期时间 **2026-09-14 00:02:33 UTC**；SAN 中的 IP 与 tyccc 一致。UTC 换成北京时间加 8 小时。证书不是“永久有效”。

定时任务实际为：

```cron
50 0,6,12,18 * * * "/root/.acme.sh"/acme.sh --cron --home "/root/.acme.sh" > /dev/null
```

它按**服务器时区**每日四次检查是否需要续期，并非每次都重新申请。acme.sh 也会参考证书机构的 ARI 建议窗口。本次部署时记录到了后续续期窗口，但没有声称已经观察到未来的自动续期成功。

节点配置完成后，还要用真实客户端验证证书链和 IP 身份。不要通过打开“允许不安全 / insecure / 跳过证书验证”绕过错误。续期失败处理见 [[证书续期与到期排错]]。

**完成标准：** 证书 SAN、有效期正确，两个部署文件存在，定时任务存在，私钥权限为 600。下一课：[[04-浏览器配置六种入口]]。
