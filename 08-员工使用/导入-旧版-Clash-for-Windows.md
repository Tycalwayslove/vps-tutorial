# 已安装旧版 Clash for Windows：导入 MEU 或 tyccc

返回 [软件与订阅总览](MEU-员工使用说明.md)。先选 **MEU（工作）**或 **tyccc（视频）**，再复制该线路对应格式的链接。本页只适用于电脑上**已经安装**旧版 Clash for Windows 的同事；这里不提供旧软件安装包，新电脑建议改用 [Clash Verge Rev](安装-Clash-Verge-Rev-Windows.md)。

在旧版 Clash for Windows 的 **Profiles／配置**页，将总览中所选线路的 **旧版 Clash 订阅**粘贴到下载地址栏，下载配置并选中它；然后在 **Proxies／代理**页选择节点，打开 **System Proxy／系统代理**。这份兼容订阅显示的节点比 v2rayN／Clash Verge Rev 少，是旧内核支持范围较窄，不代表流量额度变少。

如果地址粘贴后没有节点，先检查是否误用了“原始订阅”或“Mihomo 订阅”。旧版软件不再作为新用户首选。
