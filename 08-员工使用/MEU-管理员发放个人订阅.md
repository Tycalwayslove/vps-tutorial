# MEU 管理员发放个人订阅

员工使用的手册是 [[MEU-员工使用说明]]。**本页只供管理员看**：不要把现有的全线路测试订阅或现有的 100GB 测试订阅直接群发给所有员工。多个员工共用同一个 Sub ID，会共用一份额度，也无法分别停用和核对流量。

## 每位员工建立一个客户端

等确定员工名单后，在新 MEU 的 3x-ui 面板中为每人创建**不同的客户端**：唯一标识使用可辨认的员工编号；总流量设为 **100 GiB**；流量重置选 **每月**、日期选 **1 日**；仅关联 7 条可按客户端计量的直连入站，暂不分配 TUIC。不要复制现有客户端的 Sub ID、UUID 或密码。当前 MEU 的测试用户已核实采用 `trafficReset=monthly`、`trafficResetDay=1`、`totalGB=100 GiB`，并关联 7 条入站。

3x-ui 的同一客户端可以通过不同路径输出三种格式：原始链接、Mihomo YAML、旧版 Clash YAML。发放时只给员工使用的软件对应的地址；若他同时使用手机和电脑，可以把三种格式都交给**同一个人**。三种地址必须使用该员工的**同一个 Sub ID**，这样流量额度才共享在他自己的账号下。真实地址只写入权限受控的管理员记录，不写进 Git 仓库或本模板。

| 员工用的软件 | 发哪种链接 | MEU 每月 100 GiB 组应看到 |
|---|---|---:|
| v2rayN、v2rayNG、Shadowrocket | 原始订阅 | 7 条 |
| Clash Verge Rev、其他 Mihomo 内核客户端 | Mihomo 订阅 | 7 条 |
| 已安装的旧版 Clash for Windows | 旧版 Clash 订阅 | 2 条 |

## 发放前检查

1. 在员工客户端详情确认启用状态、100 GiB 额度、每月 1 日重置和关联的 7 条入站。
2. 用无痕窗口或不带面板登录态的请求打开三种订阅地址，确认均能返回内容。原始订阅应有 7 条分享链接；Mihomo YAML 应有 7 条代理；旧版 Clash YAML 应有 2 条兼容代理。
3. 检查三种响应的 `Subscription-Userinfo`：`total` 应为 `107374182400` 字节，即 100 GiB。此字段只是客户端展示信息；实际限制由 3x-ui 客户端额度执行。
4. 通过公司批准的私密渠道把**该员工自己的链接**发给本人，同时发送 [[MEU-员工使用说明]] 和对应安装包。不要在群里或公开知识库贴完整 URL。
5. 保存发放日期、员工编号、套餐与联系渠道。员工离职或链接泄露时，停用该客户端并轮换其订阅身份。
