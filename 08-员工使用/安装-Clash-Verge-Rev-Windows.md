# Windows：安装 Clash Verge Rev 并导入 MEU 或 tyccc

返回 [软件与订阅总览](MEU-员工使用说明.md)。先选 **MEU（工作）**或 **tyccc（视频）**，再复制该线路对应格式的链接。本软件必须使用总览中所选线路的 **Mihomo 订阅**。

## 1. 安装

普通 Windows 10／11 电脑从离线包取 `Clash-Verge-Rev/Windows/Clash.Verge_2.5.2_x64-setup.exe`，或从[项目官方发布文件](https://github.com/clash-verge-rev/clash-verge-rev/releases/download/v2.5.2/Clash.Verge_2.5.2_x64-setup.exe)下载。双击安装程序，按提示安装并打开。若安装时提示缺少 WebView2，可请管理员提供离线包里的 `Clash.Verge_2.5.2_x64_fixed_webview2-setup.exe`；不要随意下载第三方“绿色版”。

## 2. 导入并启用

1. 复制总览中所选线路的 **Mihomo 订阅**。
2. 打开软件左侧 **订阅**页面，粘贴链接并点击导入。导入完成后，点击这份订阅的**使用**。
3. 打开 **代理**页面，选一个节点。回到设置，开启**系统代理**。
4. 打开浏览器测试网页。以后节点变化时，到“订阅”页刷新。
