# Linux：安装 Clash Verge Rev 并导入 MEU 或 tyccc

返回 [软件与订阅总览](MEU-员工使用说明.md)。先选 **MEU（工作）**或 **tyccc（视频）**，再复制该线路对应格式的链接。本软件使用 **Mihomo 订阅**。当前本地离线包没有 Linux 安装文件，需要从[项目官方发布页](https://github.com/clash-verge-rev/clash-verge-rev/releases)选择与你的系统相符的版本；不确定发行版或处理器时，请管理员协助。

Debian／Ubuntu 使用 `.deb`，Fedora 等使用 `.rpm`。按[项目官方 Linux 安装说明](https://www.clashverge.dev/install.html)完成安装并打开软件。进入 **订阅**页，粘贴总览中所选线路的 **Mihomo 订阅**并导入；点“使用”，在 **代理**页选节点，然后打开系统代理。若你用的是没有图形桌面的服务器，此桌面软件不适用，请联系管理员。
